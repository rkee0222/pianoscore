# ScoreFlow

사진/PDF 피아노 악보를 **이 기기 안에서** 분석해 마디 단위 연주 타임라인을 만들고, 설정한 템포에 맞춰 악보를 자동으로 세로 스크롤하는 **완전 오프라인** 웹 앱입니다. 서버도, 계정도, 인터넷 연결도 필요 없습니다. 실제 연주 소리나 MIDI 입력은 추적하지 않습니다.

> **설계 우선순위: 정확한 타이밍 전환.** 모든 음표를 완벽히 인식하는 것보다, 마디 경계·박자표·상대적 길이·템포를 맞춰 스크롤이 제때 넘어가는 것을 목표로 합니다.

## 무엇이 달라졌나 (파이썬 백엔드 → 브라우저 단독)

이전 버전은 분석에 파이썬(FastAPI + Audiveris) 서버가 필요했습니다. 이제 분석까지 전부 브라우저에서 실행되므로 **컴퓨터 없이 태블릿(아이패드 등)만으로도** 업로드·분석·연주·저장이 가능합니다.

- **PDF 렌더링:** [pdf.js](https://mozilla.github.io/pdf.js/)로 각 페이지를 캔버스에 렌더링 (WASM/서버 불필요)
- **마디 검출:** 캔버스 픽셀의 투영 프로파일 분석으로 보표(5선)·대보표·마디선을 찾음 (`frontend/src/analysis/detect.ts`)
- **타이밍 계산:** 박자표와 BPM으로 마디별 `duration`/`startTime` 산출 (`frontend/src/analysis/timing.ts`)
- **저장/재생:** 분석 결과·이미지·보정값·타임라인을 IndexedDB에 저장, 서비스 워커가 앱 셸을 캐시 → 인터넷 없이 재열기·자동 스크롤

## 구조

```text
frontend/                         React + TypeScript + Vite PWA (이 앱의 전부)
  src/analysis/detect.ts          보표·마디선 투영 프로파일 검출 (순수 함수)
  src/analysis/timing.ts          박자표 → quarter beats → duration/startTime
  src/analysis/analyzer.ts        파일 로딩·pdf.js 렌더·canvas 래스터·Score 조립
  src/App.tsx                     업로드·보관함·보정·연주 화면
  src/timeline.ts                 타임라인 재계산/보정 로직
  src/playback.ts                 재생 시계와 스크롤 좌표 보간
  src/db.ts                       IndexedDB 저장/조회/삭제
  public/sw.js                    앱 셸 + 해시 번들 오프라인 캐시
  public/sample-score.png         포함 예제 악보
scripts/generate-sample.mjs       예제 악보 재생성 (Node, 무의존)
scripts/e2e.mjs, static-server.mjs 헤드리스 브라우저 E2E 검증용
```

파이썬은 어디에도 필요 없습니다. 유일한 요구 사항은 **정적 파일을 브라우저에 올리는 것**뿐입니다.

## 실행 방법

### 요구 사항
- Node.js 20 이상 (개발/빌드용)
- 최신 브라우저 (Chrome/Edge/Safari/Firefox)

### 1. 설치
```bash
npm --prefix frontend install
```

### 2-A. 개발 모드
```bash
npm run dev
```
브라우저에서 안내되는 주소(기본 `http://localhost:5173`)를 엽니다.

### 2-B. 프로덕션 빌드 후 정적 호스팅
```bash
npm run build      # frontend/dist 생성
npm run preview    # 로컬에서 dist 미리보기
```
`frontend/dist`는 **순수 정적 파일**입니다. 어떤 정적 호스팅(로컬 파일 서버, GitHub Pages, 사내 서버 등)에 올려도 되고, 한 번 로드하면 오프라인으로 동작합니다.

### 태블릿(아이패드 등)에서 쓰기
1. PC나 아무 정적 호스팅에 `frontend/dist`를 올리고 태블릿 브라우저로 **한 번** 접속합니다. (같은 와이파이의 PC `npm run preview` 주소도 가능)
2. 브라우저 메뉴에서 **홈 화면에 추가**(PWA 설치)합니다.
3. 이후에는 **인터넷 없이** 설치된 ScoreFlow를 열어 업로드·분석·연주·저장까지 전부 태블릿 단독으로 수행할 수 있습니다.

> 최초 1회 정적 파일을 받아오는 것만 온라인이 필요하고(설치), 그 다음부터는 분석을 포함해 완전 오프라인입니다.

## 사용 방법
1. JPG/PNG 여러 장 또는 PDF를 선택하고 **기본 템포(BPM)** 와 **박자표**를 지정합니다. 여러 입력은 선택 순서대로 하나의 세로 악보가 됩니다.
2. 분석이 끝나면 보정 화면에서 검출된 마디와 낮은 신뢰도 구간, 메모를 확인합니다.
3. 전체 BPM을 입력하고 **전체 적용**하면 각 마디의 박 수를 유지한 채 시간을 다시 계산합니다.
4. 표에서 마디별 박 수·BPM·시간·페이지·X/Y 위치를 수정하고, 위/아래 버튼으로 순서를 바꾸거나 `⧉`로 반복 마디를 복제, 수동 구간을 추가할 수 있습니다.
5. **저장하고 연주**를 누릅니다. 악보의 마디를 터치하면 그 위치에서 시작합니다.
6. 카운트다운 후 재생하며 배속·스크롤 위치를 조정합니다. 현재 마디, 진행률, 경과/남은 시간이 표시됩니다.

키보드 단축키: `Space` 재생/정지 · `←`/`→` 5초 이동 · `R` 처음 · `F` 전체 화면 · `E` 보정. 태블릿에서는 큰 컨트롤과 마디 오버레이를 터치로 사용합니다.

## 검증

```bash
npm test     # 단위 테스트 (검출·타이밍·타임라인·재생·IndexedDB)
npm run e2e  # 빌드 후 헤드리스 브라우저 전 과정 검증
```

- 단위 테스트 **15개 통과**: 투영 프로파일 검출(6), 타이밍 모델(3), 타임라인 보정(3), 재생 시계/스크롤 보간(2), IndexedDB 저장·재열기(1)
- 헤드리스 E2E **13개 통과**: 예제 클릭 → 기기 내 분석(20마디 검출) → 보정 화면 → 연주 진입 → 카운트다운 후 재생 진행 → 자동 스크롤 → 일시정지 유지 → IndexedDB 저장(이미지 포함) → **정적 서버 완전 종료 후** 서비스 워커 셸 + 저장 악보 재열기 → 서버 없이 재생

`frontend/public/sample-score.png`는 두 개의 피아노 대보표와 8마디를 그린 예제입니다. `npm run sample`로 다시 생성할 수 있습니다(Node만 사용).

## 현재 한계 (타이밍 우선 설계의 결과)

- **음표 인식은 하지 않습니다.** 기기 내 분석은 보표와 마디선의 위치만 찾고, 음표 종류·인쇄된 템포·조표는 읽지 않습니다. 각 마디는 지정한 박자표와 BPM으로 시간을 계산합니다. 마디 안에서 음이 몰리거나 늘어지는 부분(루바토 등)은 보정 화면에서 구간 시간을 직접 지정하세요.
- **마디선 검출은 스캔 품질에 민감합니다.** 기울어짐, 흐릿함, 필기 악보, 복잡한 텍스처에서는 마디 경계가 부정확할 수 있습니다. 검출이 어려우면 페이지당 4개 균일 구간으로 안전하게 대체하며, 신뢰도가 낮은 구간은 보정 표에 표시됩니다.
- **반복·D.C./D.S.·코다·페르마타·점진적 템포 변화는 자동 확장하지 않습니다.** 마디 복제와 순서 변경, 구간 시간 지정으로 실제 연주 경로를 직접 구성합니다.
- **박자표 혼재:** 곡 중간에 박자표가 바뀌면 분석 시 하나만 지정되므로, 바뀌는 마디의 박 수를 보정 표에서 조정하세요.
- **저장 용량:** 이미지가 base64로 IndexedDB에 저장되므로, 매우 큰 악보 묶음은 브라우저 저장 정책의 영향을 받습니다. 업로드는 총 80MB·PDF 30페이지로 제한됩니다.
- 실제 연주 오디오/MIDI 추적, 자동 템포 적응, 계정 동기화, 클라우드 공유는 포함하지 않습니다.
